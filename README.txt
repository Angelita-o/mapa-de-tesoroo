PROYECTO MAPA INTERACTIVO

Abre index.html en el navegador.

Estructura:
- index.html
- styles.css
- script.js
- mapa.jpeg
- imagenes/mina.jpg
- imagenes/simon.jpg
- imagenes/parque.jpg
- imagenes/casa.jpg

Cada marcador muestra una imagen diferente de la zona seleccionada. Las cuatro imágenes incluidas son recortes distintos del mapa general para que el proyecto funcione inmediatamente; puedes sustituirlas por fotografías reales manteniendo los mismos nombres de archivo.
